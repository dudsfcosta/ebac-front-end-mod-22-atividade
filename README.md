🎓 EBAC — Atividade do Módulo 22: Catálogo de Locais

## 📖 Sobre

Catálogo de locais com grid de cards:

- `locais.js` — dados dos locais (nome, slug, imagem)
- `app/components/` — Title, Grid, Paragraph e afins

## 🚀 Como rodar

```bash
npm install
npm run dev
```

## 🛠️ Tecnologias

Next.js • TypeScript

## 💡 O que aprendi

- Renderização de listas a partir de uma fonte de dados
- Componentes reutilizáveis no App Router do Next.js
